Room 1

Light

A path tracer in a fragment shader

Please touch Drag to move the camera. Tap a surface to focus on it.

Every pixel follows rays of light as they bounce around the scene, thousands of times, and averages what they find. The picture starts as noise and settles into soft shadows, reflections and glass. Drag to move the camera and watch it settle again.

Medium
GLSL ES 3.00, one fragment shader, no textures
Tests
50
Source
3,483 lines in 23 files

How it works

  • Monte Carlo integration of the rendering equation, one sample per pixel per frame.
  • Next-event estimation and multiple importance sampling keep the noise down.
  • Glass obeys Fresnel’s equations; metal uses a GGX microfacet model.
  • A thin-lens camera gives real depth of field. Tap to focus.

Room 2

World

A planet grown from a single word

Please touch Type your own name, then drag the planet round to its night side.

Type any word and it becomes the seed of a whole planet, with continents, oceans, ice caps, clouds and lights on the night side. The same word always makes the same world. Drag to turn it and pinch to come closer.

Medium
WebGL 2, seeded noise on a sphere, no textures
Tests
26
Source
3,236 lines in 18 files

How it works

  • The word is hashed into a seed, and every later choice follows from that seed.
  • Terrain is layered gradient noise, evaluated on the sphere so there are no seams.
  • Climate comes from latitude, altitude and the distance to the nearest sea.
  • The atmosphere is a single-scattering model, computed for every pixel.

Room 3

Flow

A fluid solved on a grid

Please touch Stir slowly, then quickly. Two fingers make two currents.

The fluid lives on a grid of cells, and each cell holds a velocity and a little dye. Every frame the solver carries both along the flow, then removes whatever would compress the fluid. Drag a finger through it and watch the vortices roll away.

Medium
WebGL 2, stable fluids, twenty pressure iterations
Tests
0
Source
0 lines in 0 files

How it works

  • Semi-Lagrangian advection keeps the simulation stable at any time step.
  • A pressure projection makes the velocity field free of divergence.
  • Vorticity confinement puts back the small swirls that the grid smooths away.
  • Every step runs in a fragment shader on half-float textures.

Room 4

Motion

A rigid-body physics engine

Please touch Knock the tower over, then rebuild it taller.

Boxes, balls and joints obey Newton’s laws here, sixty times a second. Stacks stand still instead of trembling, and chains swing without stretching. Pick anything up and throw it.

Medium
JavaScript, sequential impulses, a fixed 60 Hz step
Tests
0
Source
0 lines in 0 files

How it works

  • A spatial hash finds candidate pairs; the separating axis theorem tests them.
  • Contacts are solved by sequential impulses, warm-started from the frame before.
  • Stacks stay still because contact points persist from one frame to the next.
  • Joints are constraints, solved in the same pass as the contacts.

Room 5

Sound

A composer and its synthesiser

Please touch Tap play, then move the mood from calm to restless.

Nothing here is recorded. A small set of rules about harmony and rhythm writes the music one bar ahead, and a synthesiser built from oscillators and filters plays it. It does not repeat. Tap to start, then change the mood and hear it turn.

Medium
Web Audio, no samples, a look-ahead scheduler
Tests
0
Source
0 lines in 0 files

How it works

  • Chord progressions walk a graph of functional harmony.
  • Melodies follow voice-leading rules, with a seeded source of chance.
  • Every voice is synthesised from oscillators, envelopes, filters and a delay line.
  • Notes are scheduled ahead on the audio clock, so the rhythm never drifts.

Room 6

Language

A compiler to WebAssembly

Please touch Change a number and watch the bytes change with it.

Write a program in a small typed language and it is compiled, on your device, to real WebAssembly and run. Type errors are reported on the line they belong to. Edit the code and the output changes as you type.

Medium
JavaScript to WebAssembly MVP, a Pratt parser, static types
Tests
0
Source
0 lines in 0 files

How it works

  • A hand-written lexer and a Pratt parser build the syntax tree.
  • The type checker rejects a mismatch before any code is emitted.
  • The back end writes the binary module byte by byte, with no toolchain.
  • An interpreter runs the same program, and the two results must agree.

Room 7

Reason

A computer algebra system

Please touch Ask for the derivative of x to the power x.

Give it an expression and it will simplify, differentiate, integrate or solve it, showing each step it took. Arithmetic is exact, so fractions stay fractions. Every answer is then checked numerically at random points.

Medium
JavaScript, exact rationals, rule-based rewriting
Tests
0
Source
0 lines in 0 files

How it works

  • Expressions are trees, rewritten by rules until no rule applies.
  • Rational arithmetic uses arbitrary-precision integers, so nothing is rounded.
  • Integration tries a table, then substitution, then integration by parts.
  • Each result is verified by evaluating both sides at random points.

Room 8

Learning

A neural network, trained as you watch

Please touch Draw something, then watch it being learned.

A small network starts out knowing nothing and is shown a picture, one pixel at a time. With every step it adjusts its weights to be a little less wrong, and the image slowly comes into focus. Draw your own picture and it will learn that instead.

Medium
JavaScript, hand-written backpropagation, Adam
Tests
0
Source
0 lines in 0 files

How it works

  • A multilayer perceptron maps a position on the canvas to a colour.
  • Fourier features let a small network hold fine detail.
  • Gradients come from reverse-mode differentiation, written by hand.
  • The Adam optimiser takes a few hundred steps a second in a worker.

What was not verified
